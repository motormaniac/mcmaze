Queue Book keeping
push(elem): set new element's i to queueSize; queueSize += 1
pop: Get element whos i == 0; set element's i to -1; all elems i -= 1; queueSize -= 1

- Constraints (maze boundaries) have infinite edit counts

-- # Psuedocode
if queue is empty, end loop
if any graphs have an edit count above LIMIT, end loop

node = Queue pop
Filter based on adjacent cells. Filter entities are tagged either strongfilter & weakfilter or just strongfilter.
Strongfilter is more general than weakfilter.
  Set all lookups to filter 2
  for each side:
    if the side doesn't satisfy weak filter condition, set filter to 1
    if the side doesn't satisfy strong filter condition, set filter to 0

if there are lookups with filter 2
  remove all strongfilters (all filter 1s go to filter 0)

if there are lookups with filter 1 (there were no weak filters, so now we check the strong filters)
  increase edit count of this cell by 1
  queue push all occupied neighbors with edit counts less than this cell

if all filters are 0 (there were no weak or strong filters)
  increase edit count of this cell by 1
  push this cell to the queue
  unselect this cell
